# Fubar's SSTV Decoder

A portable Windows desktop SSTV receiver with satellite tracking. It has its own native window and does not start a local HTTP server or open a browser.

## Start

Run `dist/FubarsSSTVDecoder-Setup.exe` for a Windows installer. It detects existing Fubars and VB-CABLE installations and lets you skip either component. It installs Fubars, the MMSSTV engine, shortcuts, and optionally launches the bundled VB-CABLE driver setup. The driver needs administrator approval and a reboot. The installer uses an existing `Desktop/FubarsSSTVDecoder` installation when present, preserving its settings and images; fresh installs go to the current user's local Programs folder.

For a portable copy, extract `dist/FubarsSSTVDecoder-Portable.zip` and run `FubarsSSTVDecoder.exe` inside the extracted folder. Keep `_internal` and `runtime` beside the EXE. The `received_sstv` folder is created beside the EXE and stores completed images automatically.
Fresh installs select 437.550 MHz and track the ISS. The ZIP omits `settings.json`, `FubarsSSTVDecoder.ini`, the saved `iss.tle.json`, the downloaded `satellites.json`, manually added `satellites.manual.json`, and the downloaded `sstv_frequencies.json`, the catalog-wide `sstv_frequencies_all.json`, and `ui_translations.json`, so extracting an update over an existing folder leaves user settings and fresh orbit and transmitter data in place. Separate default files provide an offline ISS TLE, a starter amateur satellite catalog (including LUCA / RS90S, NORAD 67287), and ISS SSTV downlinks. A newer downloaded orbit replaces a fallback TLE when available.

To run from source, double-click **Fubar's SSTV Decoder.cmd**. Python 3.12 with NumPy, Pillow, sounddevice, and Tkinter is required. A source checkout does not include prebuilt installers. Install PyInstaller and Inno Setup 6, then run `build_portable.ps1` and `build_installer.ps1`.

## Country and language

Choose a country at the top of the window to select SSTV receive presets and its main language. Australia uses the WIA 2026 7.171 MHz 40 m SSTV centre; Italy uses the IARU Region 1 7.165 MHz image centre. The United States uses the ARRL 7.171 MHz reference. Other countries use their IARU regional image centres as a starting point; open the source band plan from **View Band Plan SSTV Frequencies** and check local allocations when needed. The country changes the preset buttons, not the current receiver frequency or satellite downlinks. Choose another language independently with the **Language** control at the top. Interface translations are fetched online and cached locally; English is shown while a translation loads or when the service is unavailable.

## Receiving

1. Select an attached RTL-SDR in **Receiver**. Press **Scan** after plugging in a dongle. The list uses each dongle's USB product name and detected tuner; a generic R820T cannot always be identified as a genuine Blog V3. Other supported SDRs, including RSPdx through SoapySDR, may also appear. For RSPdx, select **Antenna A**, **Antenna B**, or **Antenna C** before connecting. Close other SDR programs if a device is busy.
2. For ISS, select 145.800 or 437.550 MHz in **FM** mode. For HF SSTV, press **HF SSTV 14.230 USB** or **HF SSTV 7.171 LSB**; each selects its frequency and sideband with 3 kHz bandwidth. USB, LSB, and AM modes can also be selected manually. **WFM** selects a 200 kHz broadcast FM channel with mono audio and pauses the SSTV decoder. The RTL-SDR Blog V4 uses its tuner and built-in HF upconverter; direct sampling is not needed. ISS automatic reception and Doppler correction apply to FM mode.
3. Press **Tune to Selected Frequency** or Enter after editing a frequency. Preset and spectrum clicks retune an active receiver immediately, to 1 Hz entry precision. The **Driver center** readout and spectrum labels show the frequency reported by the SDR; it includes the 12 kHz digital tuning offset in HF modes and can differ from the selected ISS downlink while Doppler correction is active. The channel bandwidth starts at 12.5 kHz for FM and can be adjusted. Enter an integer PPM correction and press Enter to apply it to a connected SDR without reconnecting. **Applied PPM** shows the value accepted by the receiver.
   The spectrum uses an averaged 8k FFT with frequency and channel guides; the waterfall updates from successive IQ frames. In USB, the shaded passband is to the right of the tuning marker; in LSB, it is to the left. Drag the yellow tuning line to select a signal within the captured IQ band. The spectrum and waterfall stay at the same RF center after you release the line; audio is tuned digitally. Drag the spectrum background to move the RF center while the selected signal frequency stays put. Clicking a signal or using the wheel tunes within the current spectrum. The frequency entry and preset buttons recenter the RF receiver. Scroll over the spectrum to tune by 100 Hz per wheel step, or hold Shift for 10 Hz steps. Hover over a digit in the large MHz display and use the wheel to tune at that digit's place value, down to 1 Hz. Large digit changes recenter the receiver when they leave the visible spectrum. The vertical **RGB Floor** slider changes the displayed noise floor and waterfall colors without changing the RF signal.
   The RF gain slider takes effect during reception. For RTL-SDR, **Applied RF gain** shows the driver gain in dB. For RSPdx, moving right reduces the SDRplay IF gain reduction and increases received level; the readout shows the actual IF reduction. The **Squelch** slider mutes audio below its selected signal threshold; -120 dBFS turns it off. The **SSTV noise filter** checkbox enables a 500–3200 Hz audio bandpass for the decoder and monitor, and takes effect during reception. Scroll the Receiver tab to reach its lower controls. The speaker output selector, **Monitor received audio** checkbox, and volume slider are together there. Moving the volume slider above zero turns on speaker monitoring. Unticking the checkbox stops Fubars' speaker stream; it does not stop the separate SDR feed sent to MMSSTV. Fubars disables Windows' CABLE Output “Listen to this device” route at startup so it cannot bypass these speaker controls. Monitor playback uses the selected output's normal sample rate and a short audio buffer to avoid gaps while the UI redraws. These settings are saved on shutdown.
4. In **Satellites**, search the Amateur Radio catalog by name or NORAD number. Use Ctrl or Shift to select several entries, then press **Add Selected to Map**. To add a satellite yourself, press **Add Satellite Manually**, enter its name, SSTV frequency in MHz, and paste both TLE lines. **Save and Add to Map** stores the TLE and frequency, selects the satellite, and tunes FM. Manually added satellites remain in the Amateur Radio list after catalog updates. All tracked satellites appear by name on the map. In **Satellites on Map**, use Ctrl or Shift to select several satellites and press **Show Passes for Selected**. The next four Home passes from those satellites appear together in time order, each labeled with its satellite name. Double-click one satellite, or select one and press **Set Active for Map / Doppler**, to show its ground track, horizon ring, and Doppler readout. Press **Monitor Selected** to receive the selected satellites automatically; a dot marks monitored entries. **Stop Monitoring** removes them from automatic reception. The monitored satellites are listed below **Remove From Map**. The ISS is included even when offline. **Update Satellite Catalog** downloads fresh orbital data; the last saved catalog remains available offline. The **SatNOGS SSTV downlink** dropdown lists known active SSTV transmitters for every satellite in the Amateur Radio catalog, with a search box for names, NORAD IDs, and frequencies. Searching for a catalog satellite without a known downlink shows a manual-frequency prompt. Choosing a downlink adds that satellite to the map if needed, tunes FM, and saves the choice. Enter a MHz value under **Manual SSTV frequency** and press **Tune** to override the list for that satellite; **Clear** removes the override. **Refresh SSTV Downlinks** checks SatNOGS DB again. Transmitter data is cached for 24 hours and the included ISS list is available offline.
5. Enter your latitude and longitude in **Tracker** and save. A negative latitude means south; a negative longitude means west. The selected satellite's current and next ground tracks span complete orbits, including when no home position is set. The next orbit is a solid cyan line; the current orbit is a dashed green line. The compact list below the map shows the next four passes over your home coordinates in PC local time. Drag the map to pan, use the mouse wheel to zoom, and double-click to return to the full-world view.
6. Enter and save Home coordinates, choose an SSTV transponder for each satellite you want to monitor, and press **AUTO** beside **STOP**. AUTO arms every satellite on the map and Doppler correction; use **Monitor Selected** to arm a smaller set. Each mapped satellite has its own radio coverage ring and past/future ground path on the map. When a monitored satellite's footprint reaches Home, Fubars starts the receiver if it is off and saves completed SSTV images in `received_sstv` under that satellite's name. A receiver started by AUTO stops when that footprint leaves Home, or switches to another monitored satellite in range. A receiver started manually with **CONNECT** stays on; Doppler correction applies while the selected satellite's footprint covers Home and returns to zero outside it. **STOP** stops the receiver and disarms AUTO. A saved RF center that puts the selected channel near the edge of the capture range is recentered when receiving starts. **Update Passes** beside the Home pass list refreshes orbit data and the predictions. An ongoing pass remains listed until it ends.
7. The bundled MMSSTV engine listens to the SDR audio through VB-CABLE and detects the SSTV mode from VIS. Decoded pictures appear inside Fubars. **Save PNG** keeps the current picture, including a partial reception.

In **Decoder**, the MMSSTV engine runs in a hidden 32-bit helper process and its pictures appear in Fubars' received-image panel. Fubars selects VB-CABLE Output as the MMSSTV recording input inside the software, so the Windows default recording device can stay as it is. Fubars sends the SDR receiver audio to VB-CABLE Input. The portable ZIP includes the original VB-CABLE driver package in `VB-CABLE/VBCABLE_Driver_Pack46.zip`. Press **VB-CABLE Setup** to open its folder, extract all files, run `VBCABLE_Setup_x64.exe` as administrator, and reboot. Then press **Retry MMSSTV**. A separate PC speaker output is used only for monitoring through the controls on the Receiver tab. Click **View Image 1:1** or double-click the picture to inspect its original pixels; scrollbars appear for larger images. **Save PNG** writes the image to `received_sstv`. The **Images** tab shows the 20 most recent saved pictures as thumbnails; click one for a full-size view. **Open Image Folder** opens the received_sstv folder. **Clear Thumbnails** hides the current gallery without deleting the original pictures, and new receptions appear afterward. The cleared gallery state is saved across restarts.

VB-CABLE is made by [VB-Audio](https://www.vb-cable.com/) and is donationware; all contributions are welcome. The driver package is included unchanged. The MMSSTV engine is by JE3HHT Makoto Mori and is included under its freeware terms in `mmsstv_engine/License.TXT`. The MMSSTV application window is not part of the build.

Receiver, RF spectrum center, tracker, home coordinates, decoder, audio, window size and position, maximized state, panel sizes, map view, and selected tab are saved to `settings.json` and `FubarsSSTVDecoder.ini` when the app closes and restored on the next launch. If one settings file is missing, the other is used.
Drag the dark header or the Windows title bar to move the app. Drag the divider handles to resize its panels. The displayed PC local time and orbit calculations follow the computer's clock.

The app checks for a newer ISS TLE on startup and when **Update Selected Orbit Data** is pressed while ISS is active. It tries CelesTrak, then [AMSAT](https://www.amsat.org/tle/current/nasabare.txt) and [Where the ISS at](https://api.wheretheiss.at/v1/satellites/25544/tles). The amateur catalog uses [CelesTrak's Amateur Radio group](https://celestrak.org/NORAD/elements/gp.php?GROUP=amateur&FORMAT=JSON), with AMSAT TLEs as a fallback. Catalog downloads are limited to once every two hours, and cached data remains available offline. JSON orbital elements cover newer catalog numbers that cannot be represented in TLE format. Orbit and pass calculations use the bundled SGP4 propagator; terrain and refraction are not included.

SSTV transmitter listings come from [SatNOGS DB](https://db.satnogs.org/), whose data is [CC BY-SA](https://creativecommons.org/licenses/by-sa/4.0/). Listings describe reported transmitters; check the satellite's current activity before relying on one for a pass.

The bundled SoapySDR runtime and plugins came from the existing local Fubar's AIS Radar installation. Windows still needs a working USB driver for each SDR. The vendored [sgp4 2.27 package](https://pypi.org/project/sgp4/) is MIT licensed.
